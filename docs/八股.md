**1进程与线程**：进程是资源分配最小单位，线程是调度执行最小单位；进程间隔离，线程共享进程资源。

**2HTTP 与 HTTPS**：HTTP 明文 80 端口，不安全；HTTPS=HTTP+SSL/TLS，加密 443 端口。

**3TCP 三次握手四次挥手**：握手建连接防失效，挥手断连接保证数据传完。

**4TCP 可靠传输**：靠确认应答、超时重传、滑动窗口、拥塞控制实现。

**5IO 模型**：阻塞 IO、非阻塞 IO、IO 多路复用、信号驱动、异步 IO。

**6死锁四大必要条件**：互斥、请求保持、不可剥夺、环路等待。

**7数据库事务 ACID**：原子性、一致性、隔离性、持久性。

**8索引底层**：MySQL InnoDB 用 B + 树，减少磁盘 IO、范围查询友好。

**9缓存三大问题**：缓存穿透、缓存击穿、缓存雪崩，各有对应解决方案。

**10乐观锁 vs 悲观锁**：悲观锁遇事先上锁；乐观锁不上锁，靠版本号 / 时间戳冲突重试。
