## 阶段 1：Transformer 核心模块（1-2 周）

**目标**：能独立解释并实现 `encoder/decoder、embedding、self-attention、QKV、多头注意力` 所有细节。

### 学习内容

1. **理论复盘**

   

   - Embedding：离散符号到向量的映射、位置编码（三角函数 / 可学习）的作用
   - Self-Attention：向量化计算流程、Q/K/V 的含义、缩放点积的原因、掩码机制
   - Multi-Head Attention：多头拆分与拼接、不同头的作用
   - Encoder/Decoder 结构：残差连接、LayerNorm、前馈网络，两者的差异（如 Decoder 的 Masked Attention）

   

2. **实践任务（必做）**

   

   - 用 PyTorch 手写完整的 Scaled Dot-Product Attention
   - 手写 MultiHeadAttention 模块
   - 实现 EncoderLayer 和 DecoderLayer，拼出完整 Transformer
   - 跑一个小翻译任务（如机器翻译 toy example），验证模型可训练

   

### 验收标准

- 能画出 Transformer 的整体流程图，标注每个模块的输入输出
- 不看参考代码，能从头写出 Self-Attention 的核心逻辑
- 能解释 “为什么 Transformer 比 RNN 更适合长序列建模”

------

## 阶段 2：主流模型架构（BERT & GPT）（2-3 周）

**目标**：理解 Encoder-only（BERT）和 Decoder-only（GPT）架构的差异与设计思想。

### 学习内容

1. **BERT（Encoder-only）**

   

   - 架构：堆叠多层 Encoder，双向注意力
   - 预训练任务：Masked Language Modeling（MLM）、Next Sentence Prediction（NSP）
   - 应用场景：文本分类、命名实体识别、问答等理解类任务

   

2. **GPT（Decoder-only）**

   

   - 架构：堆叠多层 Decoder，自回归注意力（单向掩码）
   - 预训练任务：语言模型（预测下一个 token）
   - 应用场景：文本生成、对话系统、续写任务

   

3. **对比理解**

   

   - 双向 vs 单向注意力的本质区别
   - 预训练目标如何影响模型能力
   - 不同架构的优缺点与适用场景

   

### 实践任务

- 用 Hugging Face Transformers 库加载 BERT/GPT 模型，跑通文本分类 / 文本生成的微调 demo
- 尝试修改注意力掩码，观察模型输出的变化
- 画出 BERT 和 GPT 的架构对比图，标注关键差异

### 验收标准

- 能说出 BERT 和 GPT 在注意力机制、预训练目标上的核心区别
- 能判断一个任务更适合用 BERT 还是 GPT（或 Encoder-Decoder 架构）
- 能跑通一个简单的下游任务微调流程（如文本分类）

------

## 阶段 3：自监督预训练（2-3 周）

**目标**：理解自监督预训练的核心逻辑，掌握预训练 + 微调的范式。

### 学习内容

1. **自监督学习基础**

   

   - 定义：利用无标注数据，通过数据本身构建监督信号
   - 对比有监督 / 无监督 / 自监督的区别
   - 预训练 - 微调范式的优势（通用知识学习 + 下游任务适配）

   

2. **预训练核心逻辑**

   

   - 语言模型预训练：预测下一个 token 的目标函数、交叉熵损失
   - MLM 预训练：掩码预测的目标函数、掩码策略
   - 数据预处理：tokenizer、序列长度、padding、mask 的构建

   

3. **微调基础**

   

   - 预训练模型的微调流程：冻结 / 微调参数、学习率设置
   - 不同下游任务的适配：分类头、序列标注头、生成头

   

### 实践任务

- 用一个小型语料，尝试预训练一个迷你 GPT 模型（哪怕只有几层）
- 对预训练的 BERT 模型进行微调，完成一个文本分类任务
- 记录预训练和微调过程中的损失变化，分析模型收敛情况

### 验收标准

- 能解释 “为什么自监督预训练能学到通用语言知识”
- 能写出预训练目标的损失函数（如交叉熵损失）
- 能独立跑通一个 “预训练模型 + 下游任务微调” 的完整流程

------

## 阶段 4：进阶拓展（LoRA & 更多模型）（2-4 周）

**目标**：掌握高效微调技术，拓展对更多模型的理解，完成一个完整项目。

### 学习内容

1. **LoRA（低秩适配）微调**

   

   - 原理：冻结预训练模型，仅训练低秩矩阵，实现高效微调
   - 优势：显存占用低、训练速度快、适配性强
   - 实现流程：LoRA 层的插入、训练配置、权重合并

   

2. **拓展学习**

   

   - 其他高效微调方法：Adapter、Prefix Tuning
   - 更多模型架构：T5（Encoder-Decoder）、ViT（视觉 Transformer）
   - 监督学习与自监督学习的结合：半监督学习、对比学习

   

### 实践任务

- 用 LoRA 对一个预训练的大模型（如 DistilGPT2）进行微调，完成一个特定风格的文本生成任务
- 尝试对比 “全参数微调” 和 “LoRA 微调” 的显存占用、训练速度和效果差异
- 基于所学内容，完成一个完整的小项目（如：用微调后的模型做一个简单的对话机器人 / 文本分类工具）

### 验收标准

- 能解释 LoRA 的核心原理和优势
- 能独立实现 LoRA 微调的流程，完成一个下游任务
- 能清晰说明自己项目的模型架构、预训练 / 微调流程和效果

## 执行建议

1. **每周复盘**：周末花 1 小时回顾本周内容，记录难点和疑问
2. **边学边练**：每个阶段的理论内容都要配合代码实践，避免 “只看不写”
3. **循序渐进**：前一个阶段没吃透，不进入下一个阶段，比如没搞懂 Transformer 就别着急学 LoRA
4. **项目驱动**：阶段 4 的项目可以提前构思，比如 “做一个能生成特定风格文案的小模型”，带着目标学习效率更高
